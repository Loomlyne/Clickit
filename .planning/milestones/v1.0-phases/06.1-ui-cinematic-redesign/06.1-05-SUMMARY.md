## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Auto-hide bar position changed from absolute to fixed**
- **Found during:** Task 1
- **Issue:** Plan showed `absolute` positioning for the top bar, but with full-width player + flex layout, `absolute` would be scoped to the player div and not cover the sidebar. Moving to `fixed z-50` ensures it covers the full viewport consistently.
- **Fix:** Changed to `fixed top-0 left-0 right-0 z-50` and moved `onMouseMove` to the main layout div
- **Files modified:** src/components/watch/watch-page-content.tsx
- **Commit:** 78fc422

**2. [Rule 2 - Missing critical functionality] ShowCollage client component extracted**
- **Found during:** Task 2
- **Issue:** Auth page is a server component (no `'use client'`) but motion.div requires client runtime. Plan's inline code sketch would have failed without proper RSC boundary.
- **Fix:** Extracted `ShowCollage` as a dedicated `'use client'` component receiving `shows: Show[]` props. Auth page remains server component and imports MOCK_SHOWS directly.
- **Files modified:** src/components/auth/show-collage.tsx (new), src/app/auth/page.tsx
- **Commit:** 0486bd1
