# Phase 06.1 Plan 03: Navbar + Home Page + Footer Summary

Rebuilt the navbar, all home page sections, and footer using Wave 1 primitives (CinematicBackdrop, SectionHeader, ScrollReveal, GlowBadge) and Wave 2 cards (ShowCard, EpisodeArtCard). This is the most visible phase of the cinematic redesign — every visitor sees these components.

## What Was Built

**Task 1: Navbar scroll transparency (d271820)**
- Navbar is fully transparent on load — hero appears full-bleed cinematic
- Transitions to `bg-[rgba(0,0,0,0.85)] backdrop-blur-xl` after 20px scroll
- Passive `addEventListener` for performance
- Active nav links: underline pseudo-element `after:h-0.5 bg-[#5B7FFF]`, no pill backgrounds

**Task 2: HeroSlide cinematic layout (6d0e076)**
- CinematicBackdrop replaces manual radial gradient markup
- `font-display` (Playfair Display) for show title with `clamp(2.5rem, 6vw, 5rem)`
- Left-aligned bottom-third layout with left vignette + bottom gradient
- GlowBadge for streaming status, episode count badge, rating badge
- Two CTA buttons: "Watch S1 E1" (white) + "More Info" (outline)

**Task 3: RotationIndicator brand-color bars (b61aac4)**
- Replaced dot indicators with thin `h-0.5 w-12` progress bar segments
- Active segment fills with current show's brand color hex
- HeroBanner passes `activeColor={brandColorHexMap[...]}` prop
- Completed segments show at 50% white opacity

**Task 4: ContentRail with primitives (9efa882)**
- SectionHeader with brand accent color bar replaces inline h2 + link
- ScrollReveal wrapper for stagger entrance animation
- Fixed `basis-[280px]` cards — 4+ visible at once = scroll invitation
- Arrow buttons: `h-12 w-12 bg-black/60 hover:bg-black/80 backdrop-blur-sm border border-white/10`

**Task 5: GenresGrid horizontal scroll strip (0cf58fb)**
- Replaced aspect-video grid with horizontal `overflow-x-auto` pill strip
- Each genre pill: brand-color tinted background + border via inline styles
- `motion.div whileHover={{ scale: 1.05, y: -2 }}` for lift effect
- SectionHeader + ScrollReveal wrappers

**Task 6: CtaBanner brand identity (e4c4bc4)**
- True black background replaces gradient surface card
- `font-display` Playfair Display headline at `clamp(2rem, 5vw, 3.5rem)`
- 6-color brand strip (2px) at both top AND bottom — CIT signature
- Gradient CTA button: `linear-gradient(135deg, #2C3569, #9F54A0)`
- ScrollReveal entrance

**Task 7: Footer CIT branding (89782e7, ae15920)**
- `next/image` for logo (replaces raw `<img>`)
- Inline SVG social icons for YouTube, Instagram, X (Twitter)
- Column headers: `text-xs uppercase tracking-wider text-white/60`
- All link colors: `text-white/40 hover:text-white`
- 6-color brand strip at very bottom of page

**Task 8: NewEpisodesRail uses EpisodeArtCard (7662cf9)**
- Replaces custom inline card markup with `<EpisodeArtCard>` component
- Maps `getNewEpisodes()` return to EpisodeArtCard props shape
- Resolves `seasonNumber` from `MOCK_SEASONS` by `seasonId`
- Fixed `basis-[320px]` matching EpisodeArtCard's `w-[320px]`
- SectionHeader + ScrollReveal for rail consistency
