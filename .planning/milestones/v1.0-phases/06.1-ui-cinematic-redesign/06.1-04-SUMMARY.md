## What Was Built

### Series Browse Page (`/series`)
- **Mosaic hero:** 50vh hero with a 6x2 grid of show brand colors at 30% opacity under black/70 overlay — gives a cinematic "color field" effect without needing real artwork
- **Sticky genre filter:** `sticky top-16 z-40` pill bar with horizontal scroll, active genre pill uses the genre's brand color as background (via `GENRE_COLORS` map with inline styles)
- **Shows grid:** Replaced carousel with `grid-cols-2 md:grid-cols-3 lg:grid-cols-4` using `PortraitShowCard` + `ScrollReveal` for each item

### Series Detail Hero (`/series/[slug]`)
- **100vh hero:** `min-h-screen` with `CinematicBackdrop` at `intensity="high"` — show's brand color bloom fully owns the environment
- **Editorial typography:** `font-display font-bold` (Playfair Display) with `clamp(3rem, 7vw, 6rem)` for the title
- **Staggered reveal:** Motion animations with CINEMA_EASE delays for each content layer
- **Sticky mini-header:** `AnimatePresence` + `motion.div` slides down from `y: -64` when user has scrolled 70% of viewport height; shows show title + Watch Now CTA
- **Scroll indicator:** Bouncing `ChevronDown` at bottom center
- **`seasons` prop added** to accept season data for metadata row display

### Season Selector
- Replaced adaptive Tabs/Select pattern with uniform pill buttons
- Active pill uses show's `brandColorHex` as background via inline style
- `brandColorHex` flows from `SeriesDetailContent` → `SeasonSelector`

### Episode Row
- Thumbnail widened to `w-[160px] md:w-[180px]` (from 120px/140px/200px)
- `ShowArt` primitive used for thumbnail — provides brand color background, gradient overlay, watermark text
- Current episode highlight: `border-left: 3px solid {brandColorHex}` + `box-shadow: inset 4px 0 12px {brandColorHex}30` + subtle bg
- Episode number in text row tinted with brand color when current
