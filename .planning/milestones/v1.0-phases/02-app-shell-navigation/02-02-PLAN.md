This is a 36px circle button showing the first letter of the user's name. Per UI-SPEC Avatar specification:

```tsx
'use client'

import { cn } from '@/lib/utils'

interface UserAvatarProps {
  name: string
  className?: string
}

export function UserAvatar({ name, className }: UserAvatarProps) {
  return (
    <button
      aria-label="User menu"
      className={cn(
        'flex size-9 items-center justify-center rounded-full',
        'bg-secondary text-sm font-bold text-foreground',
        'transition-colors hover:bg-border',
        'focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 focus-visible:ring-offset-background',
        className
      )}
    >
      {name.charAt(0).toUpperCase()}
    </button>
  )
}
```

Key details:
- `size-9` = 36px width and height (UI-SPEC: Avatar circle 36px)
- `rounded-full` = perfect circle
- `bg-secondary` = #242430 (UI-SPEC: Surface-3 background)
- `text-sm font-bold` = 14px bold (UI-SPEC: Avatar letter typography)
- `hover:bg-border` = #2A2A36 (UI-SPEC: Avatar hover color)
- Focus ring matches shadcn pattern: `ring-ring` (#7C82A2), offset by `ring-offset-background`
- The `aria-label="User menu"` is required per UI-SPEC Accessibility Checklist
- The `aria-haspopup` and `aria-expanded` attributes will be added by Radix DropdownMenuTrigger's `asChild` prop

**Step 2: Create UserDropdown component**

Per UI-SPEC UserDropdown specification and RESEARCH Pattern 3:

```tsx
'use client'

import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu'
import { Bookmark, User, LogOut } from 'lucide-react'

interface UserDropdownProps {
  children: React.ReactNode
  onSignOut: () => void
}

export function UserDropdown({ children, onSignOut }: UserDropdownProps) {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        {children}
      </DropdownMenuTrigger>
      <DropdownMenuContent align="end" sideOffset={8} className="w-[200px]">
        <DropdownMenuLabel className="font-normal text-muted-foreground">
          viewer@example.com
        </DropdownMenuLabel>
        <DropdownMenuSeparator />
        <DropdownMenuItem>
          <Bookmark className="mr-2 size-4" />
          My List
        </DropdownMenuItem>
        <DropdownMenuItem>
          <User className="mr-2 size-4" />
          Profile
        </DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem
          className="text-brand-red-safe focus:text-brand-red-safe"
          onSelect={onSignOut}
        >
          <LogOut className="mr-2 size-4" />
          Sign Out
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

Key details:
- `align="end"` -- dropdown aligns to right edge of trigger (UI-SPEC: aligned to end)
- `sideOffset={8}` -- 8px gap below nav (UI-SPEC: offset 8px below)
- `className="w-[200px]"` -- fixed 200px width (UI-SPEC: Width 200px)
- Email label: `font-normal text-muted-foreground` -- 14px regular weight, #A1A1B5 color (UI-SPEC: Dropdown separator labels)
- Menu items use lucide icons: `Bookmark`, `User`, `LogOut` with `mr-2 size-4` (16px, 8px right margin)
- Sign Out: `text-brand-red-safe focus:text-brand-red-safe` (#DF544A) per UI-SPEC Color Specifics table
- Sign Out uses `onSelect={onSignOut}` (not onClick -- Radix DropdownMenuItem fires onSelect)
- Radix handles all keyboard nav (arrow keys, Escape, Enter, Tab), focus management, portal rendering
- The `asChild` on DropdownMenuTrigger merges trigger behavior into the UserAvatar button (adds aria-haspopup, aria-expanded)

**Step 3: Create AuthSection component**

Create `/Users/koss/Desktop/Develop/Clickit/src/components/layout/auth-section.tsx` as a CLIENT component.

Per RESEARCH Pattern 2 (Mock Auth State Toggle) and D-06/D-07:

```tsx
'use client'

import { useState } from 'react'
import { Button } from '@/components/ui/button'
import { UserAvatar } from './user-avatar'
import { UserDropdown } from './user-dropdown'

export function AuthSection() {
  const [isAuthenticated, setIsAuthenticated] = useState(false)

  if (!isAuthenticated) {
    return (
      <Button
        variant="ghost"
        size="sm"
        onClick={() => setIsAuthenticated(true)}
      >
        Sign In
      </Button>
    )
  }

  return (
    <UserDropdown onSignOut={() => setIsAuthenticated(false)}>
      <UserAvatar name="Demo User" />
    </UserDropdown>
  )
}
```

Key details:
- `useState(false)` -- starts unauthenticated (per D-06)
- Unauthenticated: `Button variant="ghost" size="sm"` -- transparent bg, white text, h-7 (28px) per UI-SPEC SignInButton spec
- `onClick={() => setIsAuthenticated(true)}` -- mock sign in (toggles to authenticated)
- Authenticated: `UserDropdown` wrapping `UserAvatar` with name "Demo User" per D-07
- `onSignOut={() => setIsAuthenticated(false)}` -- toggles back to unauthenticated
- The state persists across client-side navigations (lives in root layout's client island) but resets on hard refresh -- acceptable per RESEARCH Open Question 2
