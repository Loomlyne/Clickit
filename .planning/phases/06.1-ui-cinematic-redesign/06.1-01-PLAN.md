## Task 2: Create CinematicBackdrop primitive

**File: src/components/primitives/cinematic-backdrop.tsx**

```tsx
"use client";

interface CinematicBackdropProps {
  brandColor: string;        // hex color like "#2C3569"
  intensity?: 'low' | 'medium' | 'high';  // default 'medium'
  watermarkText?: string;    // optional large background text
  className?: string;
}
```

Render:
- `absolute inset-0 overflow-hidden` container
- Layer 1: solid black base `bg-black`
- Layer 2: radial gradient bloom using `brandColor` at 35% opacity (medium), 25% (low), 50% (high)
  - Use inline style: `background: radial-gradient(ellipse 80% 60% at 50% 120%, {brandColor}55 0%, transparent 70%)`
  - For 'high': `{brandColor}80` at center
- Layer 3 (optional): watermark text if provided
  - Absolutely centered, font-size: clamp(8rem, 20vw, 18rem), font-weight: 800
  - color: white, opacity: 0.03, user-select: none, pointer-events: none, overflow: hidden
  - Text is the `watermarkText` prop, uppercase
- Layer 4: subtle noise texture using CSS background-image (SVG data URI for grain):
  ```
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 256 256' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='noise'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.9' numOctaves='4' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23noise)' opacity='0.04'/%3E%3C/svg%3E")
  background-repeat: repeat;
  background-size: 256px;
  opacity: 0.4;
  mix-blend-mode: overlay;
  ```
