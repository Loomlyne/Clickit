## What Was Built

**ShowCard (16:9):** Rebuilt using ShowArt primitive. Motion scale 1.04 hover with spring easing `[0.16, 1, 0.3, 1]`. Bottom info overlay slides up via `translate-y-2 → translate-y-0`. Brand color hex bar (h-1) glows at bottom edge on hover with `boxShadow`. Star rating + episode count footer.

**PortraitShowCard (2:3):** Rebuilt using ShowArt with `aspectRatio="2/3"`. Same hover system as ShowCard (scale 1.03). Genre badge + title + episode count in bottom gradient overlay. Brand color bottom px glow line with `0 -4px 20px ${hex}80` shadow.

**ComingSoonShowCard:** Now wraps PortraitShowCard (previously wrapped ShowCard). GlowBadge with `pulse={true}` replaces static Badge. Click-through override div prevents navigation to non-watchable content. Brand color hex passed to GlowBadge for show-specific glow.

**EpisodeArtCard (new):** Fixed 320px wide, 16:9 ShowArt for new-episodes rail. S{n}E{n} label top-left, duration badge top-right, watch progress bar at bottom with brand color fill. Footer shows show title (muted uppercase) + episode title.

## Decisions Made

- `brandColorHexMap` already existed in `mock-data.ts` — imported directly, no local map needed.
- `EpisodeArtCard.brandColor` typed as `Show['brandColor']` to reuse the existing brand color enum for type safety.
- ComingSoonShowCard now wraps PortraitShowCard instead of ShowCard — portrait format provides a better visual for the coming-soon grid context.
