## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-10-01 | Tampering (token burn by scanners) | email links | mitigate | links go to the button page (05-23), never verify on GET (F2) |
| T-05-10-02 | Information disclosure | subject lines | mitigate | no code in the sign-in/confirm subjects (lock-screen previews); never interpolate display names in subjects (F16) |
| T-05-10-03 | Tampering | live auth config | mitigate | `supabase config push` forbidden and stated in config.toml; live values set by owner and read back by script |
| T-05-10-04 | Spoofing (open redirect) | RedirectTo | mitigate | RedirectTo is built server-side from the site origin and getSafeAuthNextPath (05-21) and must match the Supabase allow-list |
