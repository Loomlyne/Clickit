  <behavior>
    - success: one send, row sent with provider id, message acked, finishOutbox called once per batch
    - duplicate delivery of the same outboxId in one batch or a later batch after success: zero extra sends, acked
    - crash after send (finishOutbox throws once): redelivery sends again with the same key; fake Resend returns the first id; world counts one distinct provider send; row ends sent
    - 429 with retry-after 30: row retrying, message.retry({ delaySeconds: 30 }); 500: retry with backoffSeconds(attempts) = 60, 120, 240 ... capped 3600
    - 409 concurrent: retry; 409 invalid_idempotent_request: sent, provider_id null, log line 'already sent'
    - 400: failed, acked; attempts reaching MAX_ATTEMPTS (5) on a transient error: failed, acked (DB is the record)
    - first_attempt_at older than STALE_AFTER_HOURS (23): no send, failed with error 'stale_over_23h', acked
    - row leased by another consumer (claim returns nothing for it): acked without send
    - to_address null: row skipped ('no_confirmed_address'), acked, no send
    - mailer returns retry 'not_configured': row retrying, attempts not counted toward permanent failure beyond MAX_ATTEMPTS rule
    - claimOutbox throws: processBatch rethrows (whole batch retried by the queue), nothing acked
    - digest kind: message headers include List-Unsubscribe with the signed https URL and List-Unsubscribe-Post 'List-Unsubscribe=One-Click'; welcome kind has neither (digest-headers.test.ts)
    - log lines never contain an address, subject, html or token
