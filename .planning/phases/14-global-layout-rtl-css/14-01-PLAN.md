# Plan 14-01: RTL logical property migration + verification gate

## Objective

Phase 14 is a narrow-scope closure phase. Per 14-RESEARCH.md, seven of the eight RTL requirements (RTL-01, 02, 03, 04, 06, 07, 08) are already implemented in prior phases (12 and 13) and close via verification, not new code. Only RTL-05 (physical→logical CSS property migration) requires code changes: exactly four surgical className string edits across four hero/watch components. This plan executes those four edits as a single atomic commit, runs a static-invariant grep gate (Phase 13-06 pattern) proving the seven "already implemented" invariants remain intact AND the four new logical properties are present, runs `tsc --noEmit` + `npm run build` for compile-time verification, then hands off to a human-gated Vercel preview smoke test (8 items on `/ar/*`) to close all eight requirements.

## Must-Haves (goal-backward verification)

Every must_have below is verifiable via `grep` or a single shell command. No subjective criteria.

- **MH-01 (RTL-01):** `src/app/[locale]/layout.tsx` sets `dir={dir}` and `lang={locale}` on the `<html>` element — grep: `grep -n "dir={dir}" src/app/\[locale\]/layout.tsx` returns ≥1 match.
- **MH-02 (RTL-02):** `src/app/[locale]/layout.tsx` configures both Cairo and Plus Jakarta Sans with `display: 'swap'` — grep: `grep -c "display: 'swap'" src/app/\[locale\]/layout.tsx` returns `2`.
- **MH-03 (RTL-03):** `src/styles/globals.css` declares `[dir="rtl"]` body rule with `font-family: var(--font-cairo)` — grep: `grep -n 'font-family: var(--font-cairo)' src/styles/globals.css` returns ≥1 match.
- **MH-04 (RTL-04):** `src/styles/globals.css` neutralizes custom letter-spacing under Arabic — grep: `grep -n 'html\[lang="ar"\] \[class\*="tracking-\["\]' src/styles/globals.css` returns ≥1 match, and the rule block contains `letter-spacing: 0 !important`.
- **MH-05 (RTL-05):** The four target files use logical properties (`start-0`, `lg:border-s`) and contain ZERO physical `bottom-0 left-0` / `lg:border-l` at the edited sites — see T03 grep batch items (1) and (2).
- **MH-06 (RTL-06):** Carousel arrows, episode-nav chevrons, and section-header chevron retain `rtl:scale-x-[-1]` mirror classes — grep: `grep -rn "rtl:scale-x-\[-1\]" src/components/ui/carousel.tsx src/components/watch/episode-nav.tsx src/components/primitives/section-header.tsx` returns ≥5 matches total.
- **MH-07 (RTL-07):** `src/components/ui/carousel.tsx` threads `direction` into Embla options driven by `useLocale()` — grep: `grep -n "direction" src/components/ui/carousel.tsx` returns a match referencing the Embla `direction` option and locale.
- **MH-08 (RTL-08):** YouTube IFrame embed in `src/components/watch/watch-page-content.tsx` does NOT set a `dir` attribute on the player container (embed inherits LTR naturally) — grep: `grep -n 'dir="rtl"' src/components/watch/watch-page-content.tsx` returns 0 matches on the player iframe/container.

No new auth surface, no user input handling, no server actions modified, no database access paths altered, no new dependencies, no network boundaries crossed.
