## Shell Layout Contract

### `(watch)/layout.tsx` Wrapper

```
<div class="h-dvh min-h-svh overflow-hidden bg-black">
  {children}
</div>
```

| Property | Value | Reason |
|----------|-------|--------|
| `h-dvh` | `height: 100dvh` | Tracks iOS Safari dynamic toolbar |
| `min-h-svh` | `min-height: 100svh` | Stable floor when toolbar is visible |
| `overflow-hidden` | yes | Prevents iOS rubber-band scroll on the shell |
| `bg-black` | `#000000` | Pure black — no `--bg-0` (#0a0a0a) tint visible |

This is an **intermediate segment layout** (not a root layout). It MUST NOT emit `<html>` or `<body>` tags. The `[locale]/layout.tsx` already owns those.

### `WatchShell` Root Div

```
<div
  class="fixed inset-0 h-dvh min-h-svh overflow-hidden bg-black"
  data-lenis-prevent
  style="padding-bottom: env(safe-area-inset-bottom)"
>
```

| Property | Value | Reason |
|----------|-------|--------|
| `fixed inset-0` | position: fixed; top/right/bottom/left: 0 | Anchors to viewport, immune to any ancestor scroll |
| `h-dvh min-h-svh` | dynamic + stable viewport height | iOS Safari toolbar handling (same as layout wrapper — belt-and-suspenders) |
| `overflow-hidden` | yes | No scrollbar, no rubber-band |
| `bg-black` | `#000000` | Letterbox fill when player aspect doesn't fill completely |
| `data-lenis-prevent` | attribute | Belt-and-suspenders Lenis exclusion (route group escape is primary) |
| `paddingBottom: env(safe-area-inset-bottom)` | CSS env var | iOS home indicator clearance on notched devices |

z-index: default (`z-auto`). No z-index conflict exists — no Silk (z-1), no Navbar (z-20), no Footer exist in the `(watch)` route group.

### Player Container

YouTubePlayer's own outer div has `relative w-full aspect-video min-h-[200px] bg-black`. In the fullscreen context, `aspect-video` (16:9 ratio) would letterbox the player — it must be overridden without modifying the `YouTubePlayer` component.

**Override pattern:** Wrap `YouTubePlayer` in an `absolute inset-0` container inside the shell. The player's inner iframe (`absolute inset-0 w-full h-full`) then fills that container.

```
<div class="absolute inset-0">          ← override wrapper, fills the shell
  <YouTubePlayer
    videoId={episode.youtubeId ?? ''}   ← initial value ONLY, never updated via prop
    onReady={...}
    onStateChange={...}
  />
</div>
```

The override wrapper `absolute inset-0` makes the player container cover the full shell (100dvw × 100dvh). The YouTubePlayer's own `aspect-video` class is overridden by the absolute fill.

**Critical:** The `videoId` prop passed to `YouTubePlayer` is the initial episode ID only. It is NEVER updated on episode switches. Episode switches call `playerRef.current.loadVideoById(...)` directly. Updating the prop would trigger the `useEffect([videoId])` in `YouTubePlayer` which destroys and recreates the YT.Player instance — a breaking regression.

### Back Link (Minimal Placeholder)

Position: `absolute top-4 left-4 z-10` — 16px from viewport top-left, above the player iframe.

```
<div class="absolute top-4 left-4 z-10">
  <Link
    href="/series/{show.slug}"
    class="text-sm text-white/50 hover:text-white transition-colors duration-150 flex items-center gap-1"
    aria-label="Back to show"
  >
    ← Back
  </Link>
</div>
```

| Property | Value |
|----------|-------|
| Position | `absolute top-4 left-4` (16px from each edge) |
| z-index | `z-10` — above the player iframe, inside the shell stacking context |
| Font size | `text-sm` (14px) |
| Font weight | 400 regular (inherited) |
| Color at rest | `text-white/50` — `rgba(255,255,255,0.50)` |
| Color on hover | `text-white` — `rgba(255,255,255,1.0)` |
| Transition | `transition-colors duration-150` |
| Label text | `← Back` |
| `aria-label` | `"Back to show"` (English); Arabic: `"العودة للمسلسل"` |
| Touch target | The `<Link>` renders inline — the wrapping `<div>` provides a 16px guttered tap area from the viewport corner, which combined with the text height (≈20px) gives an adequate touch zone. Phase 33 will expand this to a full 44px touch target button. |
| RTL | `ArrowLeft` icon if using icon; `←` text glyph mirrors visually in RTL. Use `rtl:scale-x-[-1]` on icon if `<ArrowLeft>` is used instead of the glyph. |

**Phase 32 only:** This link is explicitly minimal and temporary. Phase 33 replaces it with a full styled chrome layer. Do not add visual chrome (backgrounds, borders, shadows, icons) beyond what is specified here.

**Cross-origin pointer events:** YouTube iframe captures all pointer events at the iframe boundary. The back link div MUST be a sibling (not a child) of the player's `absolute inset-0` wrapper, both inside the shell. Siblings at higher z-index receive pointer events correctly.

```
<div class="fixed inset-0 ...">       ← shell
  <div class="absolute inset-0">      ← player wrapper (z: auto)
    <YouTubePlayer />
  </div>
  <div class="absolute top-4 left-4 z-10">  ← back link (z: 10, receives pointer events)
    <Link ...>← Back</Link>
  </div>
</div>
```

## Copywriting Contract

| Element | Copy |
|---------|------|
| Back link label | `← Back` |
| Back link aria-label | `"Back to show"` / Arabic: `"العودة للمسلسل"` |
| Empty state heading | n/a — missing `youtube_video_id` triggers redirect, no empty state rendered |
| Error state | Redirect to `router.back()` or `/series/{show.slug}` — no visual error UI in Phase 32 |
| Destructive confirmation | n/a — no destructive actions in Phase 32 |

**Fallback (missing video ID):** When `episode.youtubeId` is null or empty, `WatchShell` must redirect immediately (using `useRouter().back()` or `router.push(/series/${show.slug})`). No broken player is rendered. No error message is displayed in Phase 32 — the redirect is the entire error handling contract.

**Loading state:** The existing `YouTubePlayer` poster/spinner loading state is reused without modification. It renders as an absolute overlay over the player container during the IFrame API initialization period. No spec changes needed for this state.

## Interaction Contract

### Episode Switching (client-side state change, not navigation)

| Step | Action | Notes |
|------|--------|-------|
| 1 | `forceFlush()` | Save outgoing episode position synchronously before any state change |
| 2 | `setCurrentEpisode(newEpisode)` | React state update — hook picks up new `episodeId` on next render |
| 3 | `playerRef.current.loadVideoById({ videoId: newEpisode.youtubeId, startSeconds: 0 })` | Seamless swap, no iframe remount, auto-plays |
| 4 | `window.history.replaceState(null, '', /${locale}/watch/${newEpisode.id})` | URL sync without Next.js re-render |

Episode switch does NOT show loading overlay (no `setIsReady(false)`). Transition is seamless — YouTube player handles buffering internally.

### iOS Safe Area

`padding-bottom: env(safe-area-inset-bottom)` on the shell div. This CSS environment variable returns `0px` on non-notched devices and `20–34px` on iPhone X and later. Applied as inline style (Tailwind does not have a built-in class for this by default without a plugin).

### Autoplay Overlay (`AutoplayOverlay`)

Wire inside `WatchShell` using `useState(showAutoplay)`. It renders as an absolute overlay positioned inside the `fixed inset-0` shell div, at the same z-level as the back link (`z-10` or above). Phase 32 only wires the existing `AutoplayOverlay` component — no visual spec changes to it.

## Accessibility

| Element | Requirement |
|---------|-------------|
| Back link | `aria-label="Back to show"` on the `<Link>` |
| Back link | Keyboard focusable (native `<Link>` / `<a>` is focusable by default) |
| Back link | Focus ring visible — Tailwind's `focus-visible:outline-white focus-visible:outline-2 focus-visible:outline-offset-2` or shadcn default ring |
| Player | YouTube native controls handle all player accessibility — no additional aria on the iframe |
| Shell div | `data-lenis-prevent` attribute (functional, not accessibility-related) |
| RTL | Back link arrow mirrors: use `rtl:scale-x-[-1]` on icon variant; `←` glyph is direction-neutral |
| iOS Autoplay | Player must not autoplay on iOS without user gesture — `YouTubePlayer` already sets `playsinline: 1`, `enablejsapi: 1`, `controls: 1` — no changes |
