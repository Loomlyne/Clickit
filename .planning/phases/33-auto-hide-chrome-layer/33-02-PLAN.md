| WatchShell → navigator.share | window.location.href passed to Web Share API — URL is same-origin, not user-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-03 | Information Disclosure | Share button — navigator.share | accept | URL shared is `window.location.href` (the current page URL, public-facing) — no PII, no private content |
| T-33-04 | Spoofing | useWatchlist / useLikes RLS | accept | Both hooks mutate Supabase via existing patterns; RLS policies block unauthorized mutations at the DB level — established pattern from all other hook usage |
| T-33-05 | Elevation of Privilege | initialSaved / initialLiked prop values | accept | Props are boolean read-only defaults; actual state is DB-authoritative — a tampered prop value at most causes a visual glitch on first paint, corrected on first toggle |
