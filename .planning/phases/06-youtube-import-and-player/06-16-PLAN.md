<objective>
Replace the Settings YouTube key field with the signed read-only status block (D-15, picture `mockups/06-q15.png` option A) and remove the `youtube_api_key` write path (YT-04).

Purpose: the key lives only in the Worker secret; admins can see whether it is set and prove it works without ever seeing it. Results are stored as audit rows (no schema change; both admins see who tested and when).

This plan edits `actions.ts` (testYouTubeKey, remove `youtube_api_key` from `integrationsSchema`) together with `advanced-tab.tsx`, because the client passes a typed object to `updateIntegrations`; removing the field in a different plan would break the build in between. It is the only wave-4 plan that touches `actions.ts`.
</objective>
