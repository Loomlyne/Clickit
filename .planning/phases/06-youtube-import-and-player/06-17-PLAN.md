| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-64 | Denial of service (quota) | paging loop | mitigate | max 4 pages, no auto-retry loop; Retry is a user click |
| T-06-65 | Supply chain | UI registry | mitigate | no new registry components (Registry Safety); guard test |
</threat_model>
