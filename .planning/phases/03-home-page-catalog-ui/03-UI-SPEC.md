# Phase 3 — UI Design Contract

> Visual and interaction contract for the home page and catalog UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Phase 3 is the visual centerpiece of the platform: a cinematic home page with hero banner, content rails, and show cards -- plus a `/series` catalog grid. All data is mock (TypeScript objects). Design tokens are inherited from Phase 1 UI-SPEC; this contract specifies Phase 3-specific layout, motion, copywriting, and component inventory.

| md | 16px | Card text area padding, section header inline padding |

| 2xl | 48px | Horizontal padding on content rail containers (desktop) |

Exceptions:
- Hero banner height: `100vh` (full viewport, per D-01)

### Hero Gradient Overlay

The hero artwork uses a multi-stop gradient overlay for text legibility:

```
background: linear-gradient(
  to right,
  rgba(10, 10, 15, 0.85) 0%,
  rgba(10, 10, 15, 0.6) 40%,
  rgba(10, 10, 15, 0.2) 70%,
  rgba(10, 10, 15, 0) 100%
),
linear-gradient(
  to top,
  rgba(10, 10, 15, 1) 0%,
  rgba(10, 10, 15, 0.4) 30%,
  rgba(10, 10, 15, 0) 60%
);
```

The bottom gradient (to top) creates the seamless fade into `--background` per D-08. The left gradient (to right) ensures text legibility for left-aligned hero content.

### Card Hover Overlay

- Overlay color: `rgba(10, 10, 15, 0.65)` -- dark enough to make the white "Watch" button clearly visible, light enough to keep artwork recognizable through the overlay
- Transition: 200ms ease-out

## Motion Contract

All animations use `motion` (framer-motion) from `motion/react`.

### Hero Carousel

| Property | Value | Source |
|----------|-------|--------|
| Auto-rotation interval | 6000ms (6 seconds) per slide | Discretion -- long enough to read title + tagline |
| Crossfade duration | 800ms | D-05 (crossfade, not slide) |
| Crossfade easing | `ease-in-out` | Discretion |
| Pause on hover | Yes | D-07 |
| Progress bar fill | Linear, 6000ms matching rotation interval | D-06 |
| Progress bar height | 3px | Discretion -- thin, premium feel |
| Progress bar position | Bottom of hero, centered, 120px wide | Discretion |
| Hero text entrance | Fade up (translateY 20px to 0, opacity 0 to 1), 500ms, 200ms delay after crossfade starts | Discretion |

## Accessibility Notes

- Hero auto-rotation pauses on hover (D-07) and MUST also pause when any hero element receives keyboard focus
- Hero rotation indicator communicates current slide via `aria-label="Show {n} of {total}"` and `aria-live="polite"` on title change
- Content rail carousels support keyboard navigation: Tab to rail, arrow keys to scroll, Enter/Space to activate card
- Show cards are focusable (`tabindex="0"`) with visible focus ring (`ring` token #7C82A2)
- "Watch" overlay button on card hover also appears on card focus (keyboard accessible)
- Placeholder cards have `aria-hidden="true"` (non-interactive, decorative)
- All hero text meets WCAG AA on gradient overlay (verified by gradient opacity values above)
- Embla carousel prev/next arrows have `aria-label="Scroll left"` / `"Scroll right"`
- `prefers-reduced-motion: reduce` -- disable auto-rotation, disable card hover scale, use instant crossfade (0ms)
