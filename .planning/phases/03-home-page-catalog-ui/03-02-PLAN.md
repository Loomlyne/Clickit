    Create `src/components/home/hero-banner.tsx` as a `'use client'` component:

    Props: `{ shows: Show[] }` -- expects the FEATURED_SHOWS array (2-3 streaming shows).

    1. **State management:**
       - `const [activeIndex, setActiveIndex] = useState(0)` -- current slide
       - `const [isPaused, setIsPaused] = useState(false)` -- hover/focus pause state
       - `const [progress, setProgress] = useState(0)` -- 0-1 float for rotation indicator fill

    2. **Reduced motion support** (per UI-SPEC Accessibility Notes, Research Pitfall 7):
       - Import `useReducedMotion` from `motion/react`
       - `const shouldReduceMotion = useReducedMotion()`
       - When `shouldReduceMotion` is true: disable auto-rotation entirely, set crossfade duration to 0ms

    3. **Auto-rotation timer** (per D-02, 6000ms interval):
       ```typescript
       useEffect(() => {
         if (isPaused || shouldReduceMotion) {
           setProgress(0)
           return
         }
         const INTERVAL = 6000
         const TICK = 50 // update progress every 50ms for smooth fill
         let elapsed = 0
         const timer = setInterval(() => {
           elapsed += TICK
           setProgress(elapsed / INTERVAL)
           if (elapsed >= INTERVAL) {
             setActiveIndex((prev) => (prev + 1) % shows.length)
             elapsed = 0
             setProgress(0)
           }
         }, TICK)
         return () => clearInterval(timer)
       }, [isPaused, shouldReduceMotion, shows.length])
       ```

    4. **Reset progress on manual slide change:** When `activeIndex` changes (from the timer), reset `progress` to 0. The useEffect above already handles this by resetting `elapsed` and `progress` together.

    5. **Container:** The hero needs to extend behind the fixed navbar. Apply `-mt-16` to negate the `pt-16` from `<main>` in the root layout (per Research Pattern 4):
       ```html
       <div
         className="-mt-16 relative h-screen w-full overflow-hidden"
         onMouseEnter={() => setIsPaused(true)}
         onMouseLeave={() => setIsPaused(false)}
         onFocus={() => setIsPaused(true)}
         onBlur={(e) => {
           // Only unpause if focus leaves the hero entirely
           if (!e.currentTarget.contains(e.relatedTarget as Node)) {
             setIsPaused(false)
           }
         }}
       >
       ```

    6. **AnimatePresence crossfade** (per D-05, Research Pattern 1):
       - Import `AnimatePresence` from `motion/react`
       - Use default `mode="sync"` (NOT `mode="wait"` -- see Research Pitfall 2)
       - Render the active HeroSlide with `key={shows[activeIndex].id}` so AnimatePresence detects the change
       ```html
       <AnimatePresence mode="sync">
         <HeroSlide
           key={shows[activeIndex].id}
           show={shows[activeIndex]}
           isActive={true}
         />
       </AnimatePresence>
       ```

    7. **RotationIndicator:** Below the AnimatePresence, render:
       ```html
       <RotationIndicator
         activeIndex={activeIndex}
         total={shows.length}
         progress={progress}
       />
       ```

    8. **aria-live region** (per UI-SPEC Accessibility Notes): Add a visually hidden `div` with `aria-live="polite"` that announces the current show title when it changes:
       ```html
       <div className="sr-only" aria-live="polite">
         Now showing: {shows[activeIndex].title}
       </div>
       ```

    9. **MotionConfig wrapper** (per Research -- reduced motion): Wrap the hero content in `<MotionConfig reducedMotion="user">` to automatically disable transform animations when the OS reduce-motion setting is on:

       ```typescript
       import { MotionConfig } from "motion/react"

         <RotationIndicator ... />
       </MotionConfig>
       ```
