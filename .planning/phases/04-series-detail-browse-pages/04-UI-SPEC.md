# Phase 4 -- UI Design Contract

> Visual and interaction contract for the series detail page and Coming Soon browse page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Phase 4 delivers two new routes (`/series/[slug]` and `/coming-soon`) and extends the mock data layer with Season and Episode types. All design decisions reference the CIT design system established in Phase 1 and the visual patterns proven in Phase 3.

## Color

Inherited from Phase 1. Phase 4 specific applications:

| Role | Value | Phase 4 Usage |
|------|-------|---------------|
| Dominant (60%) | `#0A0A0F` (`--background`) | Page background behind hero and episode list, full-bleed surfaces |
| Secondary (30%) | `#1A1A22` (`--card` / `surface-2`) | Episode row hover-off state, season selector container background |
| Accent (10%) | Per-show `brandColor` hex | Hero ambient glow, brand ribbon on episode thumbnails |
| Destructive | `#DB3F34` (`--destructive`) | Not used in Phase 4 (no destructive actions) |

### Hero Color Treatment

- Ambient glow: The show's `brandColor` hex (from `brandColorHexMap`) renders as a `radial-gradient` ellipse behind the backdrop artwork, identical to the home hero pattern in `hero-slide.tsx`
- Gradient overlay: Deep cinematic gradient with left vignette + bottom fade into `#0A0A0F` (same composite gradient approach from Phase 3 `hero-slide.tsx`)
- No hard edge between hero and content -- gradient fades seamlessly into `--background`

### Status Badge Colors

| Status | Background | Text Color | Icon |
|--------|-----------|------------|------|
| Published | none (no badge shown) | n/a | Play arrow on thumbnail hover (`text-white`) |
| Coming Soon | `bg-brand-orange` (#EA8C2E) | `text-black` (black text on orange, 11.2:1 contrast) | Clock (`lucide-react` `Clock` icon, white, on thumbnail overlay) |
| Locked | `bg-surface-3` (#242430) | `text-foreground` (#FFFFFF) | Lock (`lucide-react` `Lock` icon, white, on thumbnail overlay) |

### Episode Row State Colors

| State | Thumbnail Opacity | Row Background | Interactive |
|-------|-------------------|----------------|-------------|
| Published | 100% | transparent, `bg-surface-2/50` on hover | Yes -- links to `#` (Phase 5 watch page) |
| Coming Soon | 45% | transparent, no hover change | No -- not clickable |
| Locked | 45% | transparent, no hover change | No -- not clickable |

### Coming Soon Page ShowCard Treatment

- Shows with `status: 'coming-soon'` render using the existing `ShowCard` component
- Applied overlay: `bg-black/20` opacity reduction (~80% visible) over the artwork area
- "Coming Soon" badge overlaid on the top-right corner of the artwork using `Badge` with `bg-brand-orange text-black`

Accent reserved for: hero ambient glow (per-show brand color), brand ribbon on show cards (existing), status badges (orange for coming soon, green for streaming in future phases), primary CTA button fill (Innovative Blue).

## Interaction Specifications

### Season Selector

| Interaction | Behavior |
|-------------|----------|
| Tab click (1-5 seasons) | Switches displayed episode list instantly. No loading state (mock data is synchronous). Active tab gets `data-state="active"` styling from shadcn Tabs. |
| Dropdown selection (6+ seasons) | Opens shadcn Select popover. On selection, episode list updates. Select trigger shows "Season N" label. |
| Keyboard | Tabs: arrow keys to navigate, Enter/Space to select. Select: standard Radix Select keyboard behavior. |
| URL state | Not persisted in URL for Phase 4. Season selection is local `useState`. URL state (via nuqs) deferred to Phase 8. |
| Default | First season selected on page load. |

### Episode Row Hover

| State | Hover Behavior |
|-------|---------------|
| Published | Row background transitions to `bg-surface-2/50` over 200ms. Thumbnail shows a centered semi-transparent Play circle overlay (40px diameter, `bg-black/50`, white `Play` icon 20px). Cursor: pointer. |
| Coming Soon | No hover change. Cursor: default. Row is non-interactive. |
| Locked | No hover change. Cursor: default. Row is non-interactive. |

### Episode Row Click

| State | Click Behavior |
|-------|---------------|
| Published | Navigates to `#` placeholder (Phase 5 will wire to `/watch/[episodeId]`) |
| Coming Soon | No action |
| Locked | No action |

### Load More Button

| Interaction | Behavior |
|-------------|----------|
| Click | Appends next 20 episodes to the visible list. `visibleCount += 20`. |
| Last chunk | Button disappears when all episodes are visible (`visibleCount >= episodes.length`). |
| Initial state | First 20 episodes visible. Button shows "Load More Episodes". |

### Hero CTA Button

| Interaction | Behavior |
|-------------|----------|
| Click | Links to `#` placeholder (first published episode of first season). Phase 5 will wire to `/watch/[episodeId]`. |
| Label | "Watch S1 E1" (dynamic: uses first season number + first published episode number). If no published episodes, button reads "Coming Soon" and is disabled. |

### Motion / Animation

| Element | Animation | Timing |
|---------|-----------|--------|
| Episode row hover | `bg-surface-2/50` fade-in | 200ms ease-out (CSS transition, no motion library needed) |
| Episode thumbnail play overlay | Opacity 0 to 1 | 200ms ease-out (CSS `group-hover:opacity-100`) |
| Season selector tab switch | No animation (instant swap) | n/a |
| "More Like This" rail | Scroll-reveal fade-up | Same as home ContentRail: `whileInView` with 550ms, custom cubic-bezier `[0.16, 1, 0.3, 1]` |
| Series detail hero | No Ken Burns (static hero, not rotating) | n/a |
| Series detail hero content | Staggered reveal on mount | Same pattern as `hero-slide.tsx`: genre label 300ms delay, title 450ms, tagline 650ms, CTA 850ms. Duration 600-850ms each. Ease: `[0.16, 1, 0.3, 1]` |
| Coming Soon page sections | Scroll-reveal fade-up | Same `whileInView` as ContentRail, 550ms |

## Accessibility Requirements

| Element | Requirement |
|---------|-------------|
| Season selector (tabs) | `role="tablist"`, `role="tab"`, `aria-selected`. Handled by shadcn Tabs (Radix). |
| Season selector (select) | `role="combobox"`. Handled by shadcn Select (Radix). |
| Episode row (published) | Wrapped in `<a>` or `<Link>`. Focus-visible ring using `--ring` (#7C82A2). |
| Episode row (coming-soon/locked) | `aria-disabled="true"`. Not wrapped in a link. Status communicated via badge text (screen reader reads "Coming Soon" or "Locked"). |
| Thumbnail overlay icons | `aria-hidden="true"` (decorative -- status already communicated by badge text). |
| Episode description truncation | Full description available via `title` attribute on the truncated element. |
| Load More button | Standard `<Button>` with visible label. No special ARIA needed. |
| Hero staggered animation | Respects `prefers-reduced-motion` via motion's `useReducedMotion` -- content appears instantly without animation. |
| Coming Soon page | Section headings use `<h2>` for proper heading hierarchy under page `<h1>`. |
| Episode list | Wrapped in `<section aria-label="Episodes">` for landmark navigation. |
| Season switching | `aria-live="polite"` region announces "Showing Season {n}" on change. |
