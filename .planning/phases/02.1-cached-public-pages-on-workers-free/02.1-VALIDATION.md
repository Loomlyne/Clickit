# Phase 02.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. The full decision-to-test map is in `02.1-RESEARCH.md` § Validation Architecture. This file is the sampling contract built from it.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | node:test via `--experimental-strip-types` (erasable TS, relative `.ts` imports, no `@/` alias in tested modules); Playwright 1.58 |
| **Config file** | none for unit (flags in `package.json` `test:unit`); `playwright.config.ts` (add a preview `baseURL` project) |
| **Quick run command** | `node --experimental-strip-types --disable-warning=ExperimentalWarning --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --test tests/unit/<file>.test.ts` |
| **Full suite command** | `npm run gate:local` with the placeholder public env (heavy lock, detached) |
| **Estimated runtime** | quick about 5 s; full about 10-15 min |

Layers:
- **U**: unit tests on pure modules.
- **P**: the local workerd preview (`opennextjs-cloudflare preview`, local Supabase, Workers Cache not active locally).
- **E**: Playwright against the preview.
- **W**: a controller deploy to workers.dev, then `wrangler tail` plus read-only curl.

---

## Sampling Rate

- **After every task commit:** the quick command for the touched test file, plus `npm run lint` on touched files.
- **After every plan wave:** `npm run test:unit`. Waves that change pages also run `npm run build` plus `cf:build` under the heavy lock.
- **Before `/gsd:verify-work`:** `npm run gate:local` green. The W-layer tail sample on workers.dev is recorded in the phase report.
- **Max feedback latency:** 30 s for U, 15 min for full gate.
