## Route (asked before this discussion)

| Option | Description | Selected |
|--------|-------------|----------|
| Pay $5/month | New shows and episodes appear as soon as they are added | |
| Stay free | All public pages are built ahead of time; new content appears after the site updates | ✓ |

**User's choice:** "stay free"

---

## Rebuild trigger (asked before this discussion)

| Option | Description | Selected |
|--------|-------------|----------|
| Automatic | Starts a few minutes after the last save; needs a limited exception to the deploy rule | ✓ |
| Once a night | Runs every night if content changed | |
| Koss rebuilds by hand | Admins message him and he tells the controller to rebuild | |

**User's choice:** Automatic

---

## Admin screen after saving

| Option | Description | Selected |
|--------|-------------|----------|
| A: Status bar | One line at the top of every admin page: waiting, live or failed, with Try again | ✓ |
| B: Short pop-up | A few seconds after each save, plus an email if a rebuild fails | |
| C: Label on each show | Going live, Live or Not updated beside each show | |

**User's choice:** A, after seeing a picture of all three in the product's colors.

## Urgent changes

| Option | Description | Selected |
|--------|-------------|----------|
| Switch and takedowns | Coming Soon and hiding a show or episode work at once; a picture may stay in lists until the rebuild | ✓ |
| Only the switch | Coming Soon works at once; a hidden show stays visible for a few minutes | |
| Everything waits | Nothing skips the rebuild | |

**User's choice:** Switch and takedowns. Not yet proven on the free plan; he was told so.

---

## Scheduled episodes

| Option | Description | Selected |
|--------|-------------|----------|
| A few minutes after | Rebuild starts at the scheduled time; the video link stays out of public pages until then | |
| Exactly on time | Rebuild ahead and the browser reveals at the minute; the link may be findable early | ✓ |
| Once a night | All episodes due that day appear after a nightly rebuild | |

**User's choice:** Exactly on time, with the early-link trade-off stated in the option.

---

## When to stop and pay

| Option | Description | Selected |
|--------|-------------|----------|
| More than 1 in 100 | At least 100 tries of each; more than 1 failing stops the move | ✓ |
| Any failure at all | One failed try stops the move | |
| More than 1 in 10 | Stays on the free plan longest; about 1 in 10 could hit an error page | |

**User's choice:** More than 1 in 100
