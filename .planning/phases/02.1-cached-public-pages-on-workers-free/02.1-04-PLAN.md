Split the data layer so public pages can be static and personal state can move to the browser (D-24, D-30, D-64 "Code split", F5). | Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02.1-31 | Information disclosure | admin (service-role) client reaching a client bundle | mitigate | Client components may import only catalog-mappers and queries-user; Task 2 acceptance grep |
| T-02.1-32 | Information disclosure | getEpisodeById on the public client returning unpublished rows | mitigate | Same filters as before; anon RLS comparison recorded in the SUMMARY |
