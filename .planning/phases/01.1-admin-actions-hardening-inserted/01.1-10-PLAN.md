Runner contract (this plan creates it):
- type AdminActionEnv = { assertAdmin: () => Promise<{ id: string }>; createDb: () => AdminDb; audit: AuditWriter; logError: (label: string, err: unknown) => void }
- runAdminAction<R extends { success: boolean; wrote?: boolean }>(env, run: (ctx: { db: AdminDb; adminUserId: string; audit: AuditWriter }) => Promise<R>, opts: { fallbackError: string; revalidate: (result: R | undefined) => void | Promise<void> }): Promise<R | { success: false; error: string }>
- order: assertAdmin (a throw here returns { success:false, error: err.message or fallbackError } after logError, and neither run nor revalidate is called); createDb; run inside try/finally; finally calls revalidate when result.wrote === true, result.success === true, or run threw (result undefined, a write may have happened); revalidate errors are caught and passed to logError, never replacing the action result; a throw from run is logged with '[admin/actions] mutation failed' and returned as { success:false, error: err.message or fallbackError } (today's shape).
- In actions.ts: env = { assertAdmin, createDb: createAdminClient, audit: logAuditStrict, logError: (label, err) => console.error(label, err) }, built once at module level as a non-exported const (a 'use server' file may hold non-exported consts).
