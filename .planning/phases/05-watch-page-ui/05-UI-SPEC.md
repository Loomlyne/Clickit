# Phase 5 -- UI Design Contract

> Visual and interaction contract for the watch page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Phase 5 delivers the watch page at `/watch/[episodeId]` -- the core viewer experience. A full-width YouTube player in theater mode sits above episode metadata, prev/next navigation, and an episode quick-selector that reuses Phase 4 components. All design decisions inherit the CIT design system from Phase 1 and visual patterns from Phases 3-4.

## Color

Inherited from Phase 1. Phase 5 specific applications:

| Role | Value | Phase 5 Usage |
|------|-------|---------------|
| Dominant (60%) | `#0A0A0F` (`--background`) | Page background surrounding the player and all content sections |
| Secondary (30%) | `#1A1A22` (`--card` / `surface-2`) | Player loading state fill, episode quick-selector container background, episode row hover |
| Accent (10%) | Per-show `brandColor` hex | Player loading state brand color fill, current episode highlight ring in quick-selector |
| Destructive | `#DB3F34` (`--destructive`) | Not used in Phase 5 (no destructive actions) |

### Player Area Color Treatment

- Player container background: show's `brandColor` via `brandColorBgMap` (visible during YouTube player initialization)
- Centered `Play` icon at 48px in `text-white/20` opacity while player loads
- Once YouTube iframe loads, it fills the container completely -- no brand color visible during playback

### Current Episode Highlight (Quick-Selector)

- Active episode row in the quick-selector gets `bg-surface-2` background (persistent, not just hover)
- Left border accent: 2px solid using show's `brandColor` via `brandColorHexMap` on the current episode row
- Row text remains standard colors -- the left border provides sufficient visual distinction

### Navigation Button Colors

| State | Background | Text | Border |
|-------|-----------|------|--------|
| Default | transparent | `text-muted-foreground` (#A1A1B5) | `border-border` (#2A2A36) |
| Hover | `bg-surface-2/50` | `text-foreground` (#FFFFFF) | `border-border` (#2A2A36) |
| Disabled | transparent | `text-text-muted` (#6B6B80) | `border-border/50` |

Accent reserved for: player loading state brand color fill, current episode left-border highlight in quick-selector, episode thumbnail brand color fills (inherited from EpisodeRow).

## Interaction Specifications

### YouTube Player

| Interaction | Behavior |
|-------------|----------|
| Page load | Player container shows brand-color fill with centered Play icon (48px, `text-white/20`) while YouTube IFrame API loads |
| API ready | YouTube iframe replaces the loading state, player initializes with `autoplay: 0` (user clicks to play) |
| Video ID change | Old player destroyed via `player.destroy()`, new player created for the new video ID |
| Error (101/150) | Display fallback message: "This video is currently unavailable. Try again later." centered in the player container |
| Error (100) | Display fallback message: "Video not found. It may have been removed." |
| Fullscreen | Handled natively by YouTube player controls |
| Mobile | Inline playback (`playsinline: 1`), no auto-fullscreen on iOS |

### Player Parameters (YouTube IFrame API)

```
autoplay: 0
controls: 1
rel: 0
playsinline: 1
enablejsapi: 1
iv_load_policy: 3
origin: window.location.origin
```

Do NOT include: `modestbranding` (deprecated Aug 2023), `showinfo` (deprecated 2018), `autohide` (deprecated), `theme` (deprecated).

### Episode Navigation (Prev/Next)

| Interaction | Behavior |
|-------------|----------|
| Click "Previous" | Navigates to `/watch/{prevEpisodeId}` via Next.js Link. Cross-season: last ep of S1 goes to first ep of S2. |
| Click "Next" | Navigates to `/watch/{nextEpisodeId}` via Next.js Link. Cross-season: same logic reversed. |
| First episode of show | "Previous" button disabled (`opacity-50`, `pointer-events-none`, `aria-disabled="true"`) |
| Last episode of show | "Next" button disabled (same treatment) |
| Keyboard | Standard link keyboard navigation (Tab + Enter). Focus-visible ring using `--ring` (#7C82A2). |
| Only published episodes | Navigation skips non-published episodes. Prev/Next only traverse `status: 'published'` episodes. |

### Episode Quick-Selector

| Interaction | Behavior |
|-------------|----------|
| Season switch | Reuses `SeasonSelector` component. Switches displayed episode list. |
| Episode click | Each published episode row links to `/watch/{episodeId}`. Current episode is highlighted. |
| Current episode | Left border accent (2px solid brand color) + persistent `bg-surface-2` background. Not clickable (already on this episode). |
| Scroll position | Quick-selector does not auto-scroll to current episode (user scrolls manually). |
| Default season | The season containing the current episode is pre-selected on page load. |

### Breadcrumb

| Interaction | Behavior |
|-------------|----------|
| Show title click | Links to `/series/{showSlug}` (navigates back to series detail page) |
| Season segment | Not clickable (text only) |
| Episode segment | Not clickable (current page, displayed as white text) |
| Separator | `>` character in `text-text-muted` (#6B6B80), 8px horizontal gap on each side |

### Motion / Animation

| Element | Animation | Timing |
|---------|-----------|--------|
| Page entrance | Fade-in on metadata section | 400ms, ease `[0.16, 1, 0.3, 1]` (CINEMA_EASE), motion/react |
| Player loading | No animation (static brand-color fill with Play icon) | n/a |
| Episode nav buttons | No entrance animation (renders with page) | n/a |
| Nav button hover | Background fade-in to `bg-surface-2/50` | 200ms ease-out (CSS transition) |
| Episode row hover | Same as Phase 4: `bg-surface-2/50` fade-in | 200ms ease-out (CSS transition) |
| Quick-selector | No animation (renders with page) | n/a |

## Accessibility Requirements

| Element | Requirement |
|---------|-------------|
| YouTube player container | `role="region"`, `aria-label="Video player"`. No overlays (YouTube ToS + accessibility -- screen readers must reach YouTube's native controls). |
| Breadcrumb | `<nav aria-label="Breadcrumb">` with `<ol>` list. Current segment uses `aria-current="page"`. |
| Prev/Next buttons | Standard `<a>` links via Next.js `Link`. Disabled state uses `aria-disabled="true"` + `tabindex="-1"`. |
| Current episode in quick-selector | `aria-current="true"` on the current episode row. |
| Episode quick-selector section | `<section aria-label="Episode selector">` for landmark navigation. |
| Season switching | `aria-live="polite"` region announces "Showing Season {n}" on change (inherited from Phase 4 SeasonSelector). |
| Player error state | Error message rendered as visible text with `role="alert"` for screen reader announcement. |
| Episode not-found page | Same 404 pattern as series detail: heading + description + link back to browse. |
| Focus management | On episode navigation (prev/next click), focus moves to the player container region so keyboard users start at the top of the new episode. |
| Reduced motion | Page entrance fade-in respects `prefers-reduced-motion` via motion's `MotionConfig reducedMotion="user"`. Content appears instantly without animation. |
