**Test: WTCH-05 — No overlays on YouTube player**
```typescript
test('no elements overlay the YouTube player iframe', async ({ page }) => {
  // Wait for player region to exist
  const playerRegion = page.getByRole('region', { name: 'Video player' })
  await expect(playerRegion).toBeVisible()

  // Verify no sibling/child elements have z-index > player container
  // The player container should not have any absolutely positioned children
  // that would overlay the iframe (other than the loading state which disappears)
  const iframe = page.locator('iframe[src*="youtube.com/embed"]')
  // Once iframe is visible, loading state should be hidden
  await expect(iframe).toBeVisible({ timeout: 15000 })

  // Verify no elements with position:absolute/fixed overlap the player
  // by checking that the player region's only visible child is the iframe container
  const overlays = playerRegion.locator('[class*="absolute"]:visible')
  await expect(overlays).toHaveCount(0)
})
```
