<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Koss's terminal -> live Supabase | the manifest step uses the service role key (read-only list, download, select) |
| script -> R2 clickit-media | --execute writes objects |
| media files -> sharp/ffmpeg | untrusted image/video bytes parsed locally |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-31 | Tampering | copy overwriting a different R2 object | mitigate | differing destination throws "Destination conflict"; identical skipped; no delete call anywhere |
| T-02-32 | Tampering | live DB writes from the script | mitigate | only select/list/download on Supabase; no update/insert/delete; tests assert the fake Supabase client gets no write calls |
| T-02-33 | Elevation of privilege | malicious image exploiting the decoder | mitigate | sharp >= 0.35.5 (advisory floor); runs locally, not on the Worker; SVG never decoded for variants |
| T-02-34 | Tampering | shell injection via object keys into ffmpeg | mitigate | spawnSync with an argument array and temp file names, never a shell string |
| T-02-35 | Information disclosure | keys in reports/logs | mitigate | reports contain keys, sizes, hashes only; env values never printed |
| T-02-36 | Denial of service | cutover flag on with missing objects | mitigate | verify report with failures blocks the flag (plan 02-06 guard) |
</threat_model>
