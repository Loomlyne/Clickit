## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> finalize actions | caller supplies a key it claims to have uploaded |
| finalize -> live/local DB | writes media URL columns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-68 | Elevation of privilege | finalizing another user's avatar or an admin kind | mitigate | user/admin guard per action; finalize checks the avatars/<userId>/ prefix and kind prefix |
| T-02-69 | Tampering | finalizing a disguised file | mitigate | finalizeUploadedObject magic bytes + size; delete on refusal |
| T-02-70 | Tampering | half-applied write (DB updated, audit missing) | mitigate | core restores the previous value and deletes the new object when audit fails (tested) |
| T-02-71 | Tampering | deleting Supabase originals during migration | mitigate | previous Supabase URLs are never deleted; only R2 keys are |
| T-02-72 | Repudiation | uploads without audit | mitigate | logAuditStrict before deleting the previous object |
</threat_model>
