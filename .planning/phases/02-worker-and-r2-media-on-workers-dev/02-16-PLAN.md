| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-73 | Denial of service | loading a 50 MB video into the Worker | mitigate | 4 MiB range read only; box walker bounded by the bytes given |
| T-02-74 | Tampering | malformed box sizes causing loops | mitigate | walker stops on size < 8, size beyond buffer, or after 64 boxes (tested) |
| T-02-75 | Tampering | oversized video via presigned PUT | mitigate | head() size check with the 01.1 message; delete on refusal |
| T-02-76 | Tampering | partial write without audit | mitigate | 01.1 order kept; forced-audit-failure tests retained |
| T-02-77 | Denial of service | non-faststart hero breaks Safari playback | mitigate | refused at finalize with an actionable message |
