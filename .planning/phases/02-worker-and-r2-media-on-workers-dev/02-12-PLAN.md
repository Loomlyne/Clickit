<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> requestMediaUpload | signed-in user asks for a write URL |
| browser -> R2 S3 endpoint | presigned PUT carries arbitrary bytes |
| finalize -> MEDIA binding | server reads and deletes uploaded objects |
| local shim route -> MEDIA | dev-only write path inside the Worker |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-52 | Elevation of privilege | non-admin requesting admin kinds | mitigate | requireAdminUser per kind (same logic as assertAdmin); avatar keys scoped to the caller's id |
| T-02-53 | Tampering | oversized or disguised upload | mitigate | finalize HEAD size cap, magic-byte sniff, prefix/owner check, delete on refusal; 300 s expiry |
| T-02-54 | Tampering | stored XSS via SVG/HTML | mitigate | SVG content type refused at request; text/markup magic refused at finalize; media Worker CSP sandbox |
| T-02-55 | Tampering | key injection via filename | mitigate | keys minted server-side from a sanitized stem + random part; allowed charset tested |
| T-02-56 | Elevation of privilege | dev shim reachable in production | mitigate | LOCAL_DEV=1 and host 127.0.0.1 and HMAC token required; deploy guard refuses LOCAL_DEV; UAT checks 404 on workers.dev |
| T-02-57 | Information disclosure | R2 credentials in responses or logs | mitigate | only signed URLs returned; missing-credential errors name the variable only |
| T-02-58 | Denial of service | presign flooding | mitigate | max 3 variant URLs per call; admin/user session required; unfinalized objects are refused at finalize and can be swept later |
</threat_model>
