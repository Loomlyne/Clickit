## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> R2 presigned URL | client sends bytes directly |
| browser-made variants -> R2 | client claims a file is WebP |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-78 | Tampering | client skips its own checks | accept | client checks are UX only; finalize (02-12/02-15) is the gate |
| T-02-79 | Tampering | PNG uploaded under a WebP variant key | mitigate | isRealWebp check client-side; finalize sniffs WebP magic and deletes bad variants |
| T-02-80 | Information disclosure | presigned URL leakage | mitigate | 300 s expiry, single key, PUT only; never logged |
| T-02-81 | Denial of service | dead control when uploads fail | mitigate | signed error states with Retry; no silent failure |
</threat_model>
