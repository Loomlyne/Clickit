**Step 1: Create the Navbar server component**

Create `/Users/koss/Desktop/Develop/Clickit/src/components/layout/navbar.tsx` as a SERVER component (no 'use client' directive). This is the static shell -- the auth section (client component) will be added in Plan 02.

The Navbar must have EXACTLY these characteristics per D-01 through D-05 and the UI-SPEC:

```tsx
import Link from 'next/link'

export function Navbar() {
  return (
    <nav
      aria-label="Main navigation"
      className="fixed top-0 right-0 left-0 z-50 flex h-16 items-center justify-between px-6 backdrop-blur-lg backdrop-saturate-[1.2] bg-[rgba(10,10,15,0.75)] border-b border-white/[0.06] md:px-12"
      style={{ WebkitBackdropFilter: 'blur(16px) saturate(1.2)' }}
    >
      <Link href="/" aria-label="Clickit Story home">
        <img
          src="/brand/Clickit_final_logo.svg"
          alt="Clickit Story"
          className="h-8 w-auto"
        />
      </Link>
      {/* AuthSection placeholder -- will be added in Plan 02 */}
      <div aria-label="Auth placeholder" />
    </nav>
  )
}
```

Key implementation details:
- `fixed top-0 right-0 left-0 z-50` -- always visible, floats over content (per D-05)
- `h-16` -- 64px height (UI-SPEC: Nav bar height)
- `flex items-center justify-between` -- logo left, auth right (per D-01)
- `px-6 md:px-12` -- 24px mobile, 48px desktop padding (UI-SPEC responsive spec)
- `backdrop-blur-lg` -- 16px blur (Tailwind v4 `backdrop-blur-lg` = 16px)
- `backdrop-saturate-[1.2]` -- arbitrary value for saturate(1.2) per UI-SPEC
- `bg-[rgba(10,10,15,0.75)]` -- 75% opacity of #0A0A0F per UI-SPEC Glass Effect Color table
- `border-b border-white/[0.06]` -- ultra-subtle bottom separator per UI-SPEC
- `style={{ WebkitBackdropFilter: 'blur(16px) saturate(1.2)' }}` -- Safari fallback per RESEARCH Pitfall 1
- Logo: `<img>` tag (not next/image per RESEARCH), `h-8` = 32px height, `w-auto` preserves aspect ratio
- Logo link: `aria-label="Clickit Story home"` per UI-SPEC Copywriting Contract
- Nav: `aria-label="Main navigation"` per UI-SPEC Accessibility Checklist
- The empty `<div>` placeholder for auth keeps the justify-between layout stable; Plan 02 replaces it

The updated layout should be:

```tsx
import type { Metadata } from 'next'
import { Inter } from 'next/font/google'

import '@/styles/globals.css'
import { Navbar } from '@/components/layout/navbar'

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-inter',
  display: 'swap',
})

export const metadata: Metadata = {
  title: 'Clickit Story',
  description: 'Original shows from the UAE - streaming now',
}

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" className={`dark ${inter.variable}`}>
      <body className="bg-background text-foreground font-sans antialiased">
        <a
          href="#main"
          className="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-[60] focus:rounded-md focus:bg-background focus:px-4 focus:py-2 focus:text-foreground"
        >
          Skip to content
        </a>
        <Navbar />
        <main id="main" className="pt-16">
          {children}
        </main>
      </body>
    </html>
  )
}
```

Key details:
- Skip link uses `sr-only` (hidden) with `focus:not-sr-only` (visible on Tab) per UI-SPEC Accessibility Checklist
- Skip link z-index is `z-[60]` to appear ABOVE the nav's `z-50`
- `<main id="main" className="pt-16">` -- 64px top padding clears the fixed nav (per RESEARCH Pitfall 2)
- No max-width wrapper on body or main (per D-08, D-09)
- Existing Inter font config, metadata, dark class, bg-background -- all preserved exactly
