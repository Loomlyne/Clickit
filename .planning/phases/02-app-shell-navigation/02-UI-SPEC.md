# Phase 2 — UI Design Contract

> Visual and interaction contract for the app shell and navigation bar. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Phase 2 builds the chrome that wraps every page: a floating glass-effect navigation bar with the CIT logo and auth button, plus a full-bleed layout structure. All tokens are inherited from Phase 1. This contract specifies new visual rules for the nav bar, glass effect, layout shell, and auth states.

## Spacing Scale

Inherited from Phase 1 without modification:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, icon-to-label gaps |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, card-to-card gaps |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level vertical spacing |

Exceptions: 44px minimum touch target for interactive elements on mobile (WCAG 2.5.8). The Sign In button and avatar circle must meet this minimum.

### Phase 2 Spacing Specifics

| Element | Property | Value | Rationale |
|---------|----------|-------|-----------|
| Nav bar height | `height` | 64px (3xl token) | Tall enough for logo + touch targets, short enough to not consume viewport |
| Nav horizontal padding | `padding-inline` | 24px (lg) on mobile, 48px (2xl) on desktop | Edge breathing room scales with viewport |
| Nav breakpoint for padding | `min-width` | 768px (md breakpoint) | Switch from 24px to 48px horizontal padding |
| Content top offset | `padding-top` on main | 64px | Matches nav height so content starts below fixed nav |
| Logo height | `height` | 32px | Constrained height, auto width -- keeps wordmark readable without dominating |
| Avatar circle | `width`, `height` | 36px | Comfortable click target with 44px min-tap area via padding |
| Sign In button | `min-height` | 36px | Matches avatar height for visual consistency across auth states |

## Color

Inherited from Phase 1. The 60/30/10 split is unchanged:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0A0F` / `oklch(0.07 0.01 270)` | Page background, full-bleed surfaces |
| Secondary (30%) | `#1A1A22` / `oklch(0.14 0.01 270)` | Cards, modals, dropdown menus |
| Accent (10%) | `#2C3569` / `oklch(0.30 0.08 260)` | Primary CTA buttons, active indicators |
| Destructive | `#DB3F34` / `oklch(0.55 0.20 25)` | Destructive actions only (Sign Out confirmation if added) |

Accent reserved for (Phase 2 scope): Sign In button default variant background (primary CTA), focus ring on interactive elements.

### Phase 2 Color Specifics -- Glass Effect Nav Bar

| Property | Value | Rationale |
|----------|-------|-----------|
| Nav background | `rgba(10, 10, 15, 0.75)` | 75% opacity of `#0A0A0F`. Dark enough for white logo/text legibility (estimated 14:1+ contrast). Translucent enough to show content bleeding through for premium depth. |
| Nav backdrop filter | `blur(16px) saturate(1.2)` | 16px blur creates visible frosted glass without heavy diffusion. `saturate(1.2)` adds slight color richness to blurred content underneath. |
| Nav border bottom | `1px solid rgba(255, 255, 255, 0.06)` | Ultra-subtle separator. Visible only when content scrolls underneath. Prevents the nav from feeling "cut off" against dark backgrounds. |
| Avatar circle background | `#242430` (Surface-3 / `--secondary`) | Neutral dark surface. Not accent-colored -- the avatar is identification, not a CTA. |
| Avatar circle text | `#FFFFFF` (text-primary) | White initial letter on Surface-3 background. 11.2:1 contrast ratio. |
| Avatar hover | `#2A2A36` (Border color token) | Subtle lightening on hover to indicate interactivity. |
| Dropdown background | `#1A1A22` (Surface-2 / `--popover`) | Standard shadcn popover background. |
| Dropdown border | `#2A2A36` (`--border`) | Standard shadcn popover border. |
| Dropdown item hover | `#242430` (Surface-3 / `--accent`) | Standard shadcn accent on hover. |
| Sign Out text color | `#DF544A` (brand-red-safe) | WCAG AA-safe red tint on Surface-2 background (4.53:1). Signals destructive intent without a separate button variant. |

### Glass Effect CSS Reference

```css
.nav-glass {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 50;
  height: 64px;
  background: rgba(10, 10, 15, 0.75);
  backdrop-filter: blur(16px) saturate(1.2);
  -webkit-backdrop-filter: blur(16px) saturate(1.2);
  border-bottom: 1px solid rgba(255, 255, 255, 0.06);
}
```

**Browser support note:** `backdrop-filter` is supported in all modern browsers (Chrome 76+, Firefox 103+, Safari 9+). The `-webkit-` prefix is included for Safari compatibility. No fallback needed for the target audience.

### Component Specifications

#### Navbar

- **Rendered in:** `src/app/layout.tsx`, inside `<body>`, above `{children}`
- **Structure:** `<nav>` with `position: fixed`, glass effect styles, flex layout
- **Left side:** CIT logo SVG wrapped in `<Link href="/">`. Use `Clickit_final_logo.svg` (full wordmark). Height constrained to 32px, width auto.
- **Right side:** Conditional render -- `<SignInButton>` when unauthenticated, `<UserAvatar>` + `<UserDropdown>` when authenticated.
- **Auth detection:** For Phase 2 (frontend-only, no backend), use a hardcoded boolean or local state toggle to demonstrate both states. Real auth integration happens in Phase 8.
- **Responsive behavior:** Same layout at all breakpoints. Only horizontal padding changes (24px mobile, 48px desktop at 768px+). Logo and auth button remain at their positions.
- **Accessibility:** `<nav aria-label="Main navigation">`. Logo link has `aria-label="Clickit Story home"`. Skip-to-content link before nav for keyboard users.

#### SignInButton

- **Variant:** `ghost` from shadcn Button. Ghost is the correct choice: on the dark glass background, an outline border would compete with the subtle nav border, while a filled primary button would draw too much attention for a secondary action. Ghost keeps the nav clean -- text only with hover state.
- **Size:** `sm` (h-7, 28px) -- compact enough for the nav bar, padded to 44px tap target on mobile via touch-action area.
- **Text:** "Sign In" -- 14px, weight 400, `text-foreground` (white).
- **Hover:** `bg-muted/50` (standard ghost hover on dark).
- **Mobile:** Same component, no change. Text remains visible at all breakpoints.

#### UserAvatar

- **Shape:** Circle, 36px diameter.
- **Content:** Single uppercase letter (first character of user's display name or email).
- **Background:** `bg-secondary` (`#242430`).
- **Text:** `text-foreground` (`#FFFFFF`), 14px bold.
- **Hover:** `bg-border` (`#2A2A36`) -- subtle lightening.
- **Border radius:** `rounded-full` (50%).
- **Interaction:** Click opens UserDropdown.
- **Accessibility:** `<button aria-label="User menu" aria-haspopup="true" aria-expanded="{state}">`.

#### UserDropdown

- **Component:** shadcn DropdownMenu (wraps Radix DropdownMenu).
- **Trigger:** UserAvatar component.
- **Position:** Aligned to end (right edge of avatar), offset 8px below nav.
- **Width:** 200px fixed.
- **Animation:** Fade in + slide down 4px over 150ms ease-out. Fade out 100ms. Standard shadcn/Radix animation.
- **Header section:** User email in 12px muted text. Separated by a `<DropdownMenuSeparator>`.
- **Menu items:**
  1. "My List" -- icon: `Bookmark` (lucide), standard item
  2. "Profile" -- icon: `User` (lucide), standard item
  3. Separator
  4. "Sign Out" -- icon: `LogOut` (lucide), text color: `text-brand-red-safe` (`#DF544A`)
- **Item height:** 36px per item (comfortable touch targets).
- **Item padding:** 8px horizontal, icons 16px from left edge.
- **Keyboard:** Full arrow-key navigation, Escape to close (provided by Radix).

## Layout Shell

### Structure

```
<html lang="en" class="dark {font-variable}">
  <body class="bg-background text-foreground font-sans antialiased">
    <a class="sr-only focus:not-sr-only" href="#main">Skip to content</a>
    <Navbar />
    <main id="main" class="pt-16">  <!-- pt-16 = 64px = nav height -->
      {children}
    </main>
  </body>
</html>
```

### Layout Rules

| Rule | Value | Rationale |
|------|-------|-----------|
| Max width | None | Full bleed -- content goes edge-to-edge (D-08, D-09) |
| Page background | `bg-background` (`#0A0A0F`) | Dark cinematic foundation |
| Content top padding | `pt-16` (64px) | Prevents content from hiding behind fixed nav |
| Section horizontal padding | `px-6` (24px) mobile, `px-12` (48px) at md+ | Individual sections manage their own padding |
| Hero sections | `px-0` | Full bleed, no horizontal padding |
| Content rail sections | `px-6` / `px-12` | Standard section padding |
| Footer | Not in Phase 2 scope | Deferred |

## Responsive Breakpoints

Phase 2 uses a single breakpoint for padding scaling. The nav layout does not change.

| Breakpoint | Width | Nav Behavior |
|------------|-------|-------------|
| Mobile | < 768px | `px-6` (24px) horizontal padding. Full wordmark logo at 32px height. Same layout. |
| Desktop | >= 768px | `px-12` (48px) horizontal padding. Full wordmark logo at 32px height. Same layout. |

**No hamburger menu.** The nav has only two elements (logo + auth), so there is nothing to collapse. The same layout works at all viewport widths down to 320px.

**Logo at narrow viewports:** The full wordmark SVG (`Clickit_final_logo.svg`, viewBox 485.86x198.93, aspect ratio ~2.44:1) at 32px height renders at ~78px wide. This fits comfortably alongside the Sign In button even at 320px viewport width (78px logo + ~70px button + 48px padding + gap = ~206px, well under 320px).
