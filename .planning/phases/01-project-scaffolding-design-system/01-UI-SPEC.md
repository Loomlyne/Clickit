## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, icon-to-label gaps |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, card-to-card gaps |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level vertical spacing |

Exceptions: 44px minimum touch target for interactive elements on mobile (WCAG 2.5.8 target size)

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 16px | 400 (Regular) | 1.5 | Montreal, system-ui, -apple-system, sans-serif |
| Label | 14px | 400 (Regular) | 1.4 | Montreal, system-ui, -apple-system, sans-serif |
| Heading | 24px | 600 (Semibold) | 1.2 | Montreal, system-ui, -apple-system, sans-serif |
| Display | 48px | 700 (Bold) | 1.1 | Montreal, system-ui, -apple-system, sans-serif |

**Rationale:** CIT brand hierarchy specifies Header 82pt ExtraBold, Sub Header 50pt Bold, Body 16pt Regular, CTA 26pt Regular. These are print-optimized sizes. The web scale preserves the visual hierarchy ratios (display is 3x body, heading is 1.5x body) while using screen-appropriate sizes. The brand's ExtraBold/Bold intent maps to 700/600 weights for screen rendering.

**Weight constraint:** Only two weights are loaded to minimize font file size: Regular (400) and Bold (700). Semibold (600) is declared for headings -- if Montreal does not ship a 600 weight, the browser will synthesize from Bold (700), which is acceptable. If Montreal has a Medium (500) weight available, use 500 for headings and 700 for display instead.

**Arabic fonts (deferred):** Daken Black and Avenir Arabic are out of scope for Phase 1. Their licensing for web use requires confirmation (noted as blocker in STATE.md). The font stack includes `sans-serif` as ultimate fallback, which will render Arabic content acceptably until Phase 8+ i18n work.

## Color

### Dark Theme Foundation

| Role | Value | Usage |
|------|-------|-------|
| Background (dominant, 60%) | `#0A0A0F` | Page background, player backdrop, full-bleed surfaces |
| Surface-1 | `#111116` | Elevated containers, nav bar background (before glass effect) |
| Surface-2 (secondary, 30%) | `#1A1A22` | Cards, modals, dropdown menus, sidebar panels |
| Surface-3 | `#242430` | Hover states on cards, active nav items, input backgrounds |
| Border | `#2A2A36` | Card borders, dividers, input outlines |

**Why tinted neutrals:** Pure `#000000` to `#1A1A1A` grays feel flat and lifeless. The dark surfaces use a subtle blue-purple tint (the `0F`, `16`, `22`, `30` in the blue channel) derived from the CIT Innovative Blue, giving the dark theme cinematic depth without visible color.

### Text Colors

| Role | Value | Contrast on #0A0A0F | Contrast on #1A1A22 |
|------|-------|---------------------|---------------------|
| Primary text | `#FFFFFF` | 19.75:1 | 17.29:1 |
| Secondary text | `#A1A1B5` | 7.09:1 (est.) | 6.20:1 (est.) |
| Muted text | `#6B6B80` | 3.52:1 (large text only) | 3.08:1 (large text only) |

### CIT Brand Colors — Original (Decorative Use Only)

These original brand hex values are used ONLY for non-text decorative elements: background fills on buttons/badges, gradient stops, border accents, ribbon patterns, progress bars. Never used for text on dark backgrounds.

| Name | Value | Usage |
|------|-------|-------|
| Innovative Blue | `#2C3569` | Button fills, badge backgrounds (with white text at 11.54:1) |
| Royal Purple | `#9F54A0` | Category ribbons, badge backgrounds (with white text at 4.94:1) |
| Oasis Green | `#50A258` | Success states, status badges, "Now Streaming" indicator |
| Crimson Red | `#DB3F34` | Destructive actions background, error state fills (with black text) |
| Sunset Orange | `#EA8C2E` | "Coming Soon" badges, warning states (with black text) |
| Desert Sand & Yellow | `#F8C623` | Highlight accents, "New" badges, premium indicators (with black text) |

### CIT Brand Colors — WCAG AA-Safe Tints (Text on Dark Backgrounds)

These tinted variants pass WCAG AA (4.5:1) on ALL dark surfaces from `#000000` through `#1A1A22`. Use these whenever brand color text appears on dark backgrounds.

| Name | Original | Safe Tint | Contrast on #0A0A0F | Contrast on #1A1A22 |
|------|----------|-----------|---------------------|---------------------|
| Blue (text-safe) | `#2C3569` | `#7C82A2` | 5.24:1 | 4.59:1 |
| Purple (text-safe) | `#9F54A0` | `#AC6CAD` | 5.18:1 | 4.53:1 |
| Green (text-safe) | `#50A258` | `#50A258` | 6.25:1 | 5.47:1 |
| Red (text-safe) | `#DB3F34` | `#DF544A` | 5.18:1 | 4.53:1 |
| Orange (text-safe) | `#EA8C2E` | `#EA8C2E` | 7.80:1 | 6.82:1 |
| Yellow (text-safe) | `#F8C623` | `#F8C623` | 12.31:1 | 10.78:1 |

### Accent Usage (10% Rule)

Accent colors are reserved for these specific elements only -- never applied broadly:

| Element | Color | Form |
|---------|-------|------|
| Primary CTA buttons | Innovative Blue `#2C3569` fill | Background fill, white text |
| Active nav indicator | Innovative Blue `#7C82A2` safe tint | Underline or dot |
| Category ribbons on show cards | Per-show brand color (original hex) | Solid bar / pattern fill |
| Status badges ("Now Streaming") | Oasis Green `#50A258` | Small pill badge |
| Status badges ("Coming Soon") | Sunset Orange `#EA8C2E` | Small pill badge |
| Error / destructive actions | Crimson Red `#DB3F34` fill | Button background |
| Links / interactive text | Blue safe tint `#7C82A2` | Text color only |

### Color Harmony Sets (from CIT Brand Guidelines)

When multiple brand colors appear together, follow these pairings:

- Set 1: Royal Purple + Oasis Green
- Set 2: Crimson Red + Desert Sand & Yellow
- Set 3: Royal Purple + Sunset Orange
- Innovative Blue + White are neutral and pair with any set

## Tailwind CSS v4 Token Mapping

Tailwind v4 uses CSS-first configuration. Tokens are defined in the main CSS file, not `tailwind.config.js`.

```css
/* app/globals.css — CIT design tokens */
@import "tailwindcss";

@theme {
  /* Brand colors — original (decorative use only) */
  --color-brand-blue: #2C3569;
  --color-brand-purple: #9F54A0;
  --color-brand-green: #50A258;
  --color-brand-red: #DB3F34;
  --color-brand-orange: #EA8C2E;
  --color-brand-yellow: #F8C623;

  /* Brand colors — WCAG AA-safe tints (text on dark) */
  --color-brand-blue-safe: #7C82A2;
  --color-brand-purple-safe: #AC6CAD;
  --color-brand-green-safe: #50A258;
  --color-brand-red-safe: #DF544A;
  --color-brand-orange-safe: #EA8C2E;
  --color-brand-yellow-safe: #F8C623;

  /* Dark theme surfaces */
  --color-background: #0A0A0F;
  --color-surface-1: #111116;
  --color-surface-2: #1A1A22;
  --color-surface-3: #242430;
  --color-border: #2A2A36;

  /* Text */
  --color-text-primary: #FFFFFF;
  --color-text-secondary: #A1A1B5;
  --color-text-muted: #6B6B80;

  /* Typography */
  --font-sans: "Montreal", system-ui, -apple-system, sans-serif;

  /* Spacing (reference — Tailwind default scale covers 4/8/16/24/32/48/64) */
  /* Use: p-1 (4px), p-2 (8px), p-4 (16px), p-6 (24px), p-8 (32px), p-12 (48px), p-16 (64px) */
}
```

**Note:** This is the prescriptive reference for the executor. The actual CSS file may need additional shadcn/ui CSS custom properties (--radius, --primary, --secondary, etc.) which should be mapped from these CIT tokens during shadcn initialization.

## Accessibility Notes

- All text-on-dark combinations pass WCAG AA (4.5:1) for normal text
- Muted text (`#6B6B80`) is 3.52:1 on background -- use ONLY for large text (18px+ or 14px+ bold) or non-essential decorative labels
- Original brand colors used as background fills must pair with the correct foreground: white text on Blue/Purple, black text on Green/Red/Orange/Yellow (see contrast data above)
- Focus indicators use `--ring` (`#7C82A2`) which passes AA on all dark surfaces
- Touch targets minimum 44x44px on mobile
