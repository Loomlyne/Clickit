# Plan 34-01: Episode Tray

## Scope

Build the full Phase 34 tray in one pass:

- Add `vaul` to dependencies.
- Create `EpisodeTray` with 24px peek, half snap, full snap, season tabs, episode rows, current row state, and progress bars.
- Wire `WatchShell` tray state to player bottom offset so the tray squeezes the player instead of covering it.
- Route every episode row through `handleEpisodeSwitch()`.
- Fetch batch progress in the watch server page and pass it to the tray.
- Tighten Phase 33 idle behavior to match the roadmap: hidden on entry and visible while paused.

## Acceptance

- `/[locale]/watch/[episodeId]` keeps one iframe while tray episode selection updates video and URL.
- Player bottom offset follows tray snap state.
- Tray remains mounted with a visible bottom handle.
- Current season and current episode update after row selection.
- TypeScript passes.
