**Helper: assertAdmin()**
```typescript
async function assertAdmin() {
  const supabase = await createClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) throw new Error('Unauthorized')

  const { data: config } = await supabase
    .from('app_config')
    .select('admin_user_id')
    .single()

  if (config?.admin_user_id !== user.id) throw new Error('Unauthorized')
  return user
}
```

Import `createClient` from `@/lib/supabase/server` and `createAdminClient` from `@/lib/supabase/admin`. Import `revalidatePath` from `next/cache`. Import `z` from `zod`.

**Server Actions to implement:**

1. `createShow(data: z.input<typeof showSchema>)` — assertAdmin, validate with showSchema.parse(), insert via admin.from('shows').insert().select().single(). If `id` is provided in data, use it (for pre-generated UUID from artwork upload). revalidatePath('/admin'). Return `{ success: true, data: show }` or `{ success: false, error: string }`.

2. `updateShow(id: string, data: z.input<typeof showSchema>)` — assertAdmin, validate, admin.from('shows').update().eq('id', id).select().single(). revalidatePath('/admin'). revalidatePath(`/admin/shows/${id}`). Return result.

3. `archiveShow(id: string)` — assertAdmin, admin.from('shows').update({ archived: true }).eq('id', id). Also archive all episodes: admin.from('episodes').update({ archived: true }).eq('show_id', id). revalidatePath('/admin'). Return result.

4. `restoreShow(id: string)` — assertAdmin, admin.from('shows').update({ archived: false }).eq('id', id). Also restore episodes: admin.from('episodes').update({ archived: false }).eq('show_id', id). revalidatePath('/admin'). revalidatePath('/admin/archive'). Return result.

5. `deleteShowPermanently(id: string)` — assertAdmin. First delete storage files: admin.storage.from('show-artwork').remove([`shows/${id}/poster.webp`, `shows/${id}/hero.webp`, `shows/${id}/logo.png`]). Then delete DB record: admin.from('shows').delete().eq('id', id) (CASCADE handles seasons/episodes). revalidatePath('/admin/archive'). Return result.

6. `createSeason(data: z.input<typeof seasonSchema>)` — assertAdmin, validate, insert, then update show.season_count: admin.rpc or manual count update. revalidatePath(`/admin/shows/${data.show_id}`). Return result.

7. `updateSeason(id: string, data: Partial<z.input<typeof seasonSchema>>)` — assertAdmin, update season by id. revalidatePath for the show detail. Return result.

8. `deleteSeason(id: string, showId: string)` — assertAdmin, delete season (CASCADE deletes episodes). Update show.season_count. revalidatePath(`/admin/shows/${showId}`). Return result.

9. `createEpisode(data: z.input<typeof episodeSchema>)` — assertAdmin, validate, insert. Update season.episode_count and show.episode_count. revalidatePath. Return result.

10. `updateEpisode(id: string, data: Partial<z.input<typeof episodeSchema>>)` — assertAdmin, update. revalidatePath. Return result.

11. `archiveEpisode(id: string, showId: string)` — assertAdmin, set archived = true on episode. Update counts. revalidatePath. Return result.

12. `reorderEpisode(episodeId: string, direction: 'up' | 'down')` — assertAdmin. Get current episode (id, episode_number, season_id, show_id). Find adjacent episode by episode_number +/- 1 in same season_id. Three-step swap to avoid unique constraint violation: set current to -1, set adjacent to current's number, set current to adjacent's number. revalidatePath for show detail. Return result.

All actions return `{ success: boolean; error?: string; data?: any }` for consistent error handling in the UI.

**Important patterns:**
- Every action calls `assertAdmin()` first (defense in depth per D-12)
- All mutations use `createAdminClient()` (bypasses RLS)
- Auth check uses `createClient()` from server.ts (respects RLS, validates JWT)
- Every mutation calls `revalidatePath()` to refresh server component data
- Wrap all DB operations in try/catch, return error message on failure

import { createClient } from '@/lib/supabase/server'
import { ShowsTable } from '@/components/admin/shows-table'

export default async function AdminPage() {
