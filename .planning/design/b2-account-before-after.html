B2 account — before / after

Clickit Story · group B2 (account): (viewer)/auth, (viewer)/auth/reset-password, (viewer)/profile. Real tokens copied from src/styles/globals.css / ui.config.json; markup follows the real components. Desktop frame is 1280 wide shown at 60%, phone frame is 375 wide shown at 80%. Mock data in the real shape (viewer “Sara Haddad”, shows “Show One…”); the shared nav is a stub because it is not in this group; fonts fall back to system sans (LBC is a local font).

Rules: 44px targets · nothing under 11px · 4.5:1 · radius roles field 8 / card 12 / panel 16 / control pill Eye on every password field Turnstile: slot only

What Koss signs

  1. The six “After” pictures below replace today's look: Sign in, Sign up, Forgot, Choose a new password, Profile, Profile password change.
  2. One shared PasswordField (eye, strength meter) used by sign-in, sign-up, reset and profile; new file in components/auth, B2-only.
  3. Turnstile slot: an empty container in sign-in, sign-up and forgot. Nothing visible today.
  4. Small copy-markup change only: the two phrases in the sign-up terms line become links (same words, en + ar).
  5. Delete dead show-collage.tsx; fix auth/profile loading skeletons to match the pages.

Needs a decision (not part of the picture, default = leave as coded)

  • Password minimum: 6 at sign-up/reset, 8 in profile. Recommend 8 everywhere for new passwords (sign-in keeps accepting 6). Changing it is a behaviour change, so it waits for your word.
  • Expired reset link: opening the page without a valid link just fails on submit. A proper “link expired, request a new one” state needs new copy — not invented here.
  • Shared components for the controller: ui/tabs trigger is 35px tall and ui/checkbox shrinks to 16px at ≥640px. I work around both inside B2 files; fixing them in ui/* is for the controller to sequence.
  • Vercel BotID (botid-init.tsx, auth/actions.ts) is untouched; it belongs to Job C.
