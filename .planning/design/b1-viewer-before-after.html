Clickit Story · design-system pass, group B1 (viewer). Real tokens copied from src/styles/globals.css, real component markup and class values read from the code, real seed copy (Last Call, Review Documentary, Doctor Care, Saturn Podcast, Poets Platform). No Supabase locally, so data is mocked in the real shape. The product font is local LBC; this sheet falls back to the system font, so letter widths differ slightly. Posters are colour blocks, not artwork.

/browse/watch/series/[slug]/watch/[episodeId]/my-listshared + not changed
What changes, in five lines
  1. Targets: every control in these pages reaches 44px (41px hero CTAs, 38px season tabs, 36px list toggle, 32px player icons, 31px review buttons, 26px stars, 37px autoplay buttons).
  2. Type and contrast: nothing under 11px (9–10.5px labels fixed); 31 white-alpha text colours become --text / --text-dim / --text-mute; two true contrast failures fixed (3.5:1 and 4.49:1).
  3. Radius roles: episode and tray thumbs 14/16 → media 11, rows 10 → card 12, tray 8 → panel 16, review box 16 → field 8, shorts 10 → media 11, player arrows → pill.
  4. Real bugs: My list cards overlap on desktop and have no visible title on phones; three controls that look live but do nothing (card “+”, shorts “View all”, rail “View all” without a link); fake “K” avatar; “25:00” shown for 25 minutes; hard-coded English.
  5. One active-state colour: list and like toggles both become primary-soft with a primary icon (pink and white-fill go away); player chrome uses --bg-0 / --line instead of zinc / black-alpha; RTL: physical left/right swapped for start/end.
